# Целевые метрики Этапа 0

## Качество анализа

- Категория: accuracy ≥95% на принятом eval-наборе.
- Основной цвет: accuracy ≥90% с допуском по согласованной цветовой группе.
- Подкатегория: macro F1 ≥85%.
- Material/style/silhouette: baseline фиксируется первым прогоном; production threshold принимается после ручной разметки.
- Валидный JSON по schema: ≥99.5% после одного разрешённого retry.
- Доля полей, исправленных пользователем: <20% после beta tuning.

## Очистка изображения

- Технический success rate ≥90% всех валидных загрузок.
- Сохранение оригинала: 100%.
- Доля подтверждений cutout без повторной обработки: целевое ≥80%.
- Критические потери деталей (рукава, лямки, каблуки): <3% eval-набора.

## Задержка

- p95 upload intent <500 ms.
- p50 full pipeline <20 s; p95 <60 s — начальная beta-цель.
- UI показывает наблюдаемый прогресс или этап, не фиктивный процент.

## Стоимость

- Считать отдельно storage, egress, CV compute, OpenAI input/output image tokens и retries.
- Первая цель: измеримая стоимость на одну подтверждённую вещь; лимит принимается после сравнения Sol/Terra/Luna.
- Аномалия: >2 AI-вызовов или >3 processing attempts на одну вещь.

## Методика

- Один frozen eval-набор, одинаковые prompt/schema и параметры для сравниваемых моделей.
- Отчёт содержит model snapshot, latency p50/p95, стоимость, schema success и метрики по каждому полю.
- Не оптимизировать prompt на test split; выделить train/dev/test после расширения набора до 200 изображений.
