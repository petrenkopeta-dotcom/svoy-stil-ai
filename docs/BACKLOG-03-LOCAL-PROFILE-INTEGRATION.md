# BACKLOG-03 — интеграция честного локального профиля

## Что подготовлено

`LocalProfileEntry` — изолированный entry/status-компонент для уже существующего локального профиля. Он явно показывает «Профиль на устройстве» и «Без аккаунта», использует нейтральный абстрактный placeholder и повторяет privacy-границу: настройки и обучение хранятся локально в текущем браузере.

Компонент не содержит входа, регистрации, синхронизации, сетевых вызовов или выбора аватара. Четыре A/B-направления и 27 кандидатных аватаров не использованы.

## Инструкция интегратору

В `src/main.jsx` импортировать:

```jsx
import { LocalProfileEntry } from "./LocalProfileEntry.jsx";
```

В `Header` заменить текущую круглую кнопку `.avatar` с `UserRound` на:

```jsx
<LocalProfileEntry onOpen={openProfile} />
```

Не добавлять обработчики auth/sync и не передавать `syncAdapter`, пока рабочий backend и доказанный пользовательский контур отсутствуют. Существующий `LocalWarmProfilePanel` и его keyboard trap/Escape/возврат фокуса оставить без изменений.

После интеграции удалить неиспользуемый импорт `UserRound`, если он больше нигде не нужен. Затем проверить desktop/mobile header: на узкой ширине privacy-текст визуально скрывается, но остаётся доступен скринридеру; название и статус остаются видимыми.

## Контрольный список

- Tab переводит фокус на entry, Enter/Space открывают существующий диалог.
- Escape закрывает диалог, фокус возвращается на entry.
- В header видны «Профиль на устройстве» и «Без аккаунта».
- Нет действий «Войти» или «Синхронизировать» и нет внешних запросов.
- Privacy-копирайт остаётся в entry и в существующей панели.
- A/B-визуалы и кандидатные аватары не подключены.
