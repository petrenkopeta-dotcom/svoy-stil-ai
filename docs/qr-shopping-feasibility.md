# BACKLOG-05 P1 — QR feasibility gate

Статус исследования: **PASS (спецификация готова), продуктовый gate: HOLD / NO-GO для реализации**  
Дата проверки источников: 16.08.2026  
Область: только сценарий «в магазине считать код вещи и добавить её в гардероб». Код продукта, A/B-визуалы и аватары не затрагиваются.

## Управленческий вывод

Сканирование технически осуществимо, но «QR вещи» не является единым российским товарным интерфейсом. На одежде могут встречаться обычный EAN/UPC, российский код маркировки **GS1 DataMatrix**, QR/ Data Matrix с **GS1 Digital Link** либо собственный QR ритейлера. Код обычно даёт идентификатор, а не достаточную карточку для стилиста. Название, категория, цвет, размер, состав и фотография должны приходить из доказанного источника данных и подтверждаться пользователем.

Рекомендация: **не начинать production-разработку сканера** до подтверждения легального и стабильного источника каталожных данных. Разрешить только технический spike на тестовом наборе кодов и UX-прототип, явно помеченный «поиск по коду», с обязательным fallback на фото и ручное заполнение. Не обещать проверку подлинности: для российского кода маркировки официальный потребительский контур — приложение «Честный ЗНАК».

## Что именно можно сканировать

| Носитель | Что извлекаем | Роль в продукте | Решение |
|---|---|---|---|
| EAN-13, EAN-8, UPC-A/UPC-E (1D) | GTIN после проверки контрольной цифры | Поиск модели товара в каталоге; экземпляр не идентифицирует | **Допустить в spike** |
| GS1 DataMatrix (включая российскую маркировку) | GS1 element string: как минимум GTIN, при наличии serial и другие AI | Идентификатор товара/экземпляра; статус оборота и подлинность нельзя выводить без ответа доверенной системы | **Допустить в spike**, локально разбирать только необходимые AI |
| QR Code с GS1 Digital Link URI | HTTPS URI и GS1-идентификаторы, например `/01/{GTIN}` и `/21/{serial}` | Ссылка на данные brand owner/resolver | **Допустить условно** после URI-валидации и сетевой модели безопасности |
| Data Matrix с GS1 Digital Link URI | То же, но не GS1 element string | Альтернативный 2D-носитель Digital Link | **Допустить условно** |
| Собственный QR ритейлера/бренда | URL, SKU или непрозрачный payload | Работает только по договорённому формату и каталогу конкретного партнёра | **Не делать универсальным**; allowlist интеграций |
| Произвольный QR URL, текст, платёжный QR | Непроверенный payload | Не является надёжным идентификатором одежды | **Отклонять**, URL автоматически не открывать |

GS1 различает GS1 DataMatrix с element string и QR/Data Matrix с GS1 Digital Link URI. GS1 также предупреждает, что переход retail POS на 2D ещё не завершён, поэтому 1D-коды остаются практически необходимыми. Российская обязательная маркировка одежды и текстиля использует Data Matrix; официальное приложение потребителя умеет проверять одежду, текстиль и обувь.

## Откуда брать товарные данные

Приоритет и доверие должны быть явными:

1. **API/выгрузка ритейлера или бренда по договору** — предпочтительный источник полной карточки: GTIN/SKU, название, категория, вариант, цвет, состав, изображения, версия и права на использование. Нужны SLA, лицензия на изображения и тест покрытия.
2. **Verified by GS1 / данные владельца GTIN** — годится для проверки существования идентификатора и базовых данных производителя, но не следует предполагать полное покрытие атрибутов, нужных стилисту. Сервис сообщает, что данные предоставляются производителями.
3. **GS1 Digital Link resolver / страница brand owner** — лишь механизм перехода к связанным ресурсам. Сам URI не гарантирует полноту, истинность, пригодность лицензии или машиночитаемую карточку.
4. **«Честный ЗНАК»** — доверенный российский контур статуса маркированного экземпляра. Публичный потребительский путь подтверждён через официальное приложение; кассовый/API-доступ описан для участников оборота с ключом доступа. До отдельного договора и технической документации нельзя проектировать стороннее приложение так, будто оно имеет такой доступ.
5. **Фото + ручные поля** — обязательный fallback и текущий реалистичный путь проекта. Результат кода может предзаполнить поля, но пользователь проверяет и исправляет их до сохранения.

Минимальная нормализованная запись с provenance:

```text
identifier_type, gtin, serial?, retailer_sku?, source,
source_record_id?, fetched_at?, source_version?,
title?, category?, color?, size?, material?, image_url?,
field_confidence/provenance, user_confirmed_at
```

Не хранить полный сырой код маркировки, serial, криптохвост или URL, если они не нужны после сопоставления. Для гардероба сохранять минимальный идентификатор и подтверждённые пользователем атрибуты.

## Предлагаемый пользовательский поток

1. Пользователь выбирает «Сканировать код»; до камеры показывается назначение и локальная/сетевая обработка.
2. Сканер распознаёт только перечисленные форматы, ограничивает размер payload и выполняет локальную синтаксическую проверку.
3. Приложение показывает тип кода и просит согласие **до** обращения к внешнему каталогу. Произвольные ссылки не открываются.
4. Поиск идёт только к allowlist-провайдеру. Карточка всегда показывает источник и статус: «найдено», «частично», «не найдено», «нельзя проверить».
5. Пользователь сверяет вещь и редактирует атрибуты. Никакой результат сканирования сам не переводит вещь в `ready`.
6. Если данных нет, код повреждён, сеть/камера недоступна или категория не поддержана — перейти к фото либо ручному добавлению без потери введённого.

### Fallback на фото

Использовать существующий local-first photo intake: проверка сигнатуры/MIME/лимитов, нормализованная canvas-копия без EXIF, отдельное согласие на локальное хранение, IndexedDB и ручная проверка. Фото не означает production AI/CV: автоматическое распознавание и удаление фона остаются HOLD. Пользователь может также продолжить без фото, заполнив категорию, название, цвет и стиль вручную.

## Privacy и security threat model

| Угроза | Последствие | Обязательная мера |
|---|---|---|
| QR phishing / deep link / `javascript:`, `data:`, `file:` или custom scheme | Переход на вредоносный ресурс, запуск приложения | Никогда не открывать payload; принимать только локально распознанный GS1 либо `https`; показывать домен; allowlist провайдеров |
| SSRF через backend fetch URL из кода | Доступ к internal/metadata endpoints | Не проксировать произвольный URL; DNS/IP egress policy, запрет private/link-local/loopback, redirect revalidation, timeout и лимит ответа |
| Огромный/сложный payload, decode bomb, camera loop | DoS, зависание | Лимиты длины/частоты/кадра, timeout, один активный запрос, отмена и rate limit |
| Подмена наклейки или копия валидного кода | Неверная карточка/ложная «подлинность» | Не заявлять authenticity; сверка изображения/названия/размера пользователем; для статуса направлять в официальный контур |
| Утечка serial/истории сканов/магазина/времени | Профилирование покупок и перемещений | Data minimisation; история off по умолчанию; не логировать raw code; короткий TTL; export/delete; аналитика только по согласию |
| Камера захватывает людей, документы и интерьер | Личные данные и чувствительный контекст | Обработка кадров on-device; не сохранять/не отправлять кадры сканера; явный camera permission; стоп камеры при background/unmount |
| Внешние изображения и tracking pixels | Передача IP/referrer/cookies третьей стороне | Прокси/кэш только после правового решения или placeholder; строгий CSP/referrer policy; лицензия и размеры |
| Каталог возвращает HTML/script или вредоносный текст | XSS/content injection | Строгая JSON schema, escaping, запрет HTML, лимиты полей |
| Смешение demo/personal или неверный provenance | Пользователь принимает чужие/демо-данные за свои | Явная source-маркировка; отдельное подтверждение; audit поля; неизвестное остаётся unknown |

До сетевого запуска требуется privacy review применимости 152-ФЗ: цели, состав и сроки обработки, согласие там, где оно является основанием, договоры с операторами/провайдерами, локализация и трансграничная передача. Этот документ не является юридическим заключением.

## Acceptance criteria для следующего gate

### Контракт и покрытие

- [ ] Зафиксирован закрытый список форматов, GS1 AI и максимальных размеров payload; есть валидные/невалидные/усечённые fixtures.
- [ ] Контрольная цифра GTIN проверяется; GS1 DataMatrix и GS1 Digital Link различаются корректно; неизвестные AI сохраняются только временно либо игнорируются безопасно.
- [ ] На согласованной выборке минимум 200 реальных предметов из целевых магазинов измерены: scan success, GTIN match, полнота `category/color/image`, mismatch и latency; выборка и магазины версионированы.
- [ ] Есть договорённый провайдер данных, документация API, лицензия, rate limits, SLA, правила удаления и provenance каждого поля.
- [ ] Не менее 90% успешных ответов содержат корректные `title + category`; целевой порог для `color + usable image` устанавливается после baseline, а не выдумывается заранее.

### UX и fallback

- [ ] Пользователь видит источник, неполноту и отсутствие проверки подлинности; все поля редактируемы до сохранения.
- [ ] Код не найден/не читается, нет камеры, permission denied, offline, timeout, 4xx/5xx и rate limit ведут к фото/ручному вводу без тупика и потери данных.
- [ ] Фото следует действующему photo-intake/storage contract; сетевой AI и удаление фона не заявляются.
- [ ] Проверены Edge/Chrome/Safari на целевых мобильных разрешениях, клавиатура, screen reader, touch targets, поворот экрана и остановка камеры.

### Privacy/security

- [ ] До consent нет внешней сети; кадры камеры и raw payload отсутствуют в telemetry, logs, crash reports и storage.
- [ ] Пройдены тесты malicious QR, non-HTTPS schemes, redirects, private IP/localhost, oversized payload/response, XSS strings, replay и rate limiting.
- [ ] Есть data inventory, retention/delete/export, vendor/legal review и incident kill switch для каждого провайдера.
- [ ] UI и документация не называют поиск по коду «проверкой подлинности» и не обещают рабочий QR до evidence.

## GO / NO-GO

**Сейчас: NO-GO для production и HOLD для включения в продукт.** Не доказаны провайдер товарных данных, права на данные/изображения, покрытие российских магазинов, доступ к статусам «Честного ЗНАКА», браузерная совместимость и security/privacy gate.

**GO только на ограниченный технический spike**, если он не попадает в пользовательский релиз: локальный decoder EAN/UPC + GS1 DataMatrix + GS1 Digital Link, синтетические и обезличенные fixtures, mock provider, без хранения raw serial и без заявления о подлинности.

**GO для закрытой альфы** — только после выполнения всех acceptance criteria, с feature flag/kill switch, allowlist одного провайдера и фото/ручным fallback. Расширение на собственные QR конкретных сетей принимается отдельно для каждой интеграции.
