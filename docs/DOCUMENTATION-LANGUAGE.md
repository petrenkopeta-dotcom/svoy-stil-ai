# Язык проектной документации

**Обязательное правило:** вся новая и обновляемая документация проекта пишется на русском языке.

Исключения допустимы только для имён файлов, программных сущностей, API, событий аналитики, UTM-параметров, команд, кода, машинных значений, официальных названий продуктов и ссылок на источники. Статусы `PASS`, `HOLD` и `NO-GO` допустимы, если рядом есть русское пояснение.

Английские заголовки и англоязычный деловой текст не допускаются. При редактировании существующего документа англоязычные фрагменты вокруг изменяемого раздела переводятся на русский без изменения машинных идентификаторов.
